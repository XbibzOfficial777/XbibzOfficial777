## About

I build command-line tools and automation systems, mostly in Python. My work centers on AI agents, developer tooling, and trading infrastructure, with a focus on code that stays readable, testable, and reliable once it moves beyond the prototype stage.

I tend to work iteratively: get a working core running first, then refine the architecture, error handling, and interfaces until the project holds up in real use.

## Projects

- **[BibzCode](https://github.com/XbibzOfficial777/BibzCode)**: An autonomous terminal agent that turns a request into a plan, executes it with filesystem, shell, Git, web, and Python tools, and streams progress back to the terminal. Supports seven model providers and runs in Android Termux.
- **DeepSeek CLI**: A multi-provider AI agent framework with tool calling, multi-agent orchestration, browser automation, and MCP connectors. Currently at v7.7.
- **Indodax Trading Bot**: A cryptocurrency trading bot for the Indodax exchange, rebuilt as a packaged application with a test suite, a terminal UI, and full documentation.
- **[YtMusicScraper](https://github.com/XbibzOfficial777/ytmusicscraper)**: A tool for extracting YouTube Music data.

## Stack

**Primary:** Python · Bash · JavaScript · TypeScript

## Working principles

- Ship a working core first, then iterate.
- Prefer explicit, testable code over clever abstractions.
- Treat automation like software: validate inputs, handle failure paths, and make what it does visible in logs.
